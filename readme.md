# 电磁场与电磁波实验 课程说明

## 主要内容

0.5学分实验课，主要是熟悉AWR V10 软件（很老的软件了），理解 S21/S11等参数，并使用AWR进行参数最优化

## 课程要点

刚开始软件会很难熟悉（这种是射频使用的EDA工具），如果今后想做射频、通信硬件方向，可以考虑多熟悉熟悉；然后是嵌入式、物联网、控制工程等数字电路、软件固件方向，此门课了解即可。

## 期末考试形式

是前面几次课的实验，抽一个（除了第一个软件熟悉实验课）进行当堂的实验仿真及最优化要求操作（比如分频段的S21/S11增益要求），老师会提前说明考试的范围进行抽题。

如果比较害怕当场发挥不稳定，可以提前准备好实验文件，直接运行优化，2分钟即可结束考试（提前准备没有关系，允许的）；也可以网络查找资料，但不能交流。
